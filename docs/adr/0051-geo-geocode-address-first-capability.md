# geo.geocode-address as the first Geo Capability

The first Geo Capability in Exito Tools is `geo.geocode-address`, exposed as `exito geo geocode-address --city <city> --address <address>` and as the TUI Action `Geocode address`. It maps the external geocoder response to a small domain-owned result containing only message, success, latitude, longitude, status, normalized address, neighborhood, and DANE code.
